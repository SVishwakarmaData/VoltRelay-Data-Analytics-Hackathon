# Dataset Documentation

## Dataset Overview

This project uses a multi-table battery-swapping network dataset provided for the Gradient Learnings Data Analytics Hackathon.

The dataset covers January 2024 to June 2025 and approximately 3.87 million battery-swapping events across six Indian cities.

## Dataset Categories

The analysis uses data relating to:

- Swap events
- Stations
- Batteries
- Riders
- Support tickets
- Fleet partners
- Station-hourly status
- City daily context

## Data Availability

The raw dataset is not included in this repository. Please refer to the hackathon-provided dataset source and access permissions.

## Usage

The notebook contains the data preparation, SQL/DuckDB queries, analysis, and findings.
